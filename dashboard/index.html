How the implied value is priced

Each protocol is priced like its own category already prices itself. Take the protocols in the same category whose token already trades, read their market-cap-to-TVL ratios off this snapshot, and use the median — shrunk toward the global median (—) by eight phantom peers so one odd peer cannot set a category's price, and clamped between 0.06 and 0.65. Multiply that peer multiple by TVL, then adjust: seven-day TVL momentum (clamped −30%…+40%, half weight), maturity (a protocol that has run longer with no token earns up to +20%), and multi-chain reach (+1.5% per extra chain, up to five). Every row also carries a confidence score: how much evidence stands behind its price — peer depth, age, TVL stability and scale. It never moves the ranking; it tells you how hard to lean on the number. Wrapped, staked, bridged and exchange products are excluded: they are another token's product, not a launch. Protocols whose token already trades are never ranked — they sit in the comparison strip at the bottom at the market's own value. An implied value is this board's claim, not a prediction that a token will be issued. Click any row for its full breakdown and farm plan.
